# روش‌های آماری — کتاب تعاملی

نسخهٔ کامل وب از جزوهٔ روش‌های آماری. استاد: دکتر سکینه دهقان؛ گردآورنده: احسان شهبازی.

## ساختار

`dist/` وبسایت مستقل است: خواندن فصل‌ها، جست‌وجو، نشان‌گذاری، تنظیمات متن و پوسته، PDF.js، ۹ آزمایشگاه تعاملی و ۵ نمودار اصلی بازطراحی‌شده. وابستگی‌های زمان اجرا، فونت‌ها، منبع لاتک و PDF همگی محلی‌اند؛ CDN و سرویس تحلیلی ندارد. وضعیت مطالعه تنها در localStorage مرورگر ذخیره می‌شود.

برای پیش‌نمایش: `python3 -m http.server 4173 --directory dist`

## بازسازی محتوا

`npm ci`، سپس ساخت یک محیط مجازی در `.venv` و نصب `requirements-build.txt` در آن؛ سپس `npm run build` و `npm test`.

اسکریپت `tools/build_book.py` ابتدا فایل اصلی جزوه در پوشهٔ همسایهٔ Statistical Methods را می‌خواند. اگر فایل اصلی وجود نداشته باشد، از `dist/assets/lecture.tex` استفاده می‌کند. در حالت دوم PDF را جداگانه از خروجی همان فایل به‌روز کنید. این تبدیل، متن و فرمول‌ها و جدول‌ها را حفظ و شکل‌های TikZ را با نسخه‌های SVG معادل جایگزین می‌کند. HTML تولیدشده از منبع کنترل‌شدهٔ کتاب ساخته می‌شود، نه از ورودی کاربران.

## کنترل صحت

`npm run check` و `npm test`: بررسی نحو، رندر ۶۲۳ عبارت ریاضی، مقادیر مرجع نرمال/کای‌دو/استیودنت/دوجمله‌ای، پوشش ۳۹ بخش، ۵ نمودار و ۹ آزمایشگاه زمینه‌ای.

آزمایشگاه‌ها مثال‌های آموزشی‌اند: احتمال دوجمله‌ای، نرمال، اریبی و MSE، حد مرکزی، پوشش فاصلهٔ اطمینان، واریانس، داده‌های زوجی، مقدار p و توان آزمون. فرض‌های هر مدل در رابط ذکر شده‌اند. نمونه‌گیری تصادفی در مرورگر با بذر قابل تکرار انجام می‌شود؛ مقدار p و چندک نرمال از تقریب عددی با خطای کوچک به دست می‌آید.

هیچ داده‌ای از دانشجو به سرور ارسال نمی‌شود. راهنمای انتشار روی GitHub Pages در `GITHUB_PAGES.md` آمده است.

## دانلود فصل به فصل

فایل‌های `dist/assets/chapters/` شامل PDF و لاتک مستقل چهار فصل، راهنما و پیوست هستند. هر فایل TEX همهٔ تعریف‌ها و شکل‌های لازم را دارد و با XeLaTeX مستقل کامپایل می‌شود. `npm run build` این خروجی‌ها را نیز از منبع کامل بازسازی می‌کند؛ اجرای مستقیم `python3 tools/build_chapter_exports.py` نیز ممکن است. اسکریپت به XeLaTeX و PyMuPDF نیاز دارد. این وابستگی‌ها تنها برای تولید خروجی هستند و سایت استاتیک برای اجرا به آن‌ها نیاز ندارد.

## حرکت رابط

`dist/motion.js` حرکت‌های قابل‌قطع مودال‌ها، تغییر محتوا و شکل‌های SVG را مدیریت می‌کند. تغییرات سازگارِ نمودار با درون‌یابی مختصات اجرا می‌شوند؛ تغییر ساختار، گذار محو دارد. محاسبات و برچسب‌ها مستقیماً نتیجهٔ نهایی را گزارش می‌کنند. ترجیح `prefers-reduced-motion` دستگاه رعایت می‌شود.
